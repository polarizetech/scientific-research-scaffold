# Agent configuration

`skills/new-study/` is a Claude Code skill for creating and adopting studies with this scaffold. To use it,
copy the folder to `~/.claude/skills/` (for you) or `.claude/skills/` (for one repo).

The rules every study and sim carries for coding assistants are not here: they are in each generated
`CLAUDE.md`, and in `AGENTS.md`, which the preregistration kit installs and keeps up to date.
