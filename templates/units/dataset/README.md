**Question.** {{question}}

A dataset analysis in the sense of the study protocol. The data is referenced, never committed; the
analysis is preregistered before its outcome is opened; every number is regenerated by `analysis/`.

| | |
|---|---|
| `DATASET.toml` | where the data lives (a dataset-fetch reference pinned to a version), its licence, and the selection criteria |
| `analysis/` | the program that reads the pinned data and produces every number, in named stages |
| `preregistrations/<EID>/` | `PREREG.md` (predictions and the analysis plan, tagged before the outcome is opened), `DEVIATIONS.md`, `RESULTS.md` |

## The order

1. **Select**: criteria first, then a candidate that meets them; record its accession, pinned version and
   licence, and set `status = "selected"`.
2. **Check the method on the data** without opening the outcome: can the measurement be made at all?
3. **Preregister**: predictions, the analysis plan, the stage that first opens the outcome, and what an
   adequate test of the smallest effect of interest needs. Tag it.
4. **Run** the staged analysis from the pinned data; report against the frozen plan, with deviations logged.
5. **Write back**: the result goes to the research corpus as a finding.
